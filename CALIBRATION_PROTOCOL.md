# PET Quest V42 — Calibration Protocol

PET Readiness is an internal learning index, not a Cambridge score and not a pass probability.

## Evidence collection
Record the prediction before the external result is known, then link it to an official exam, external mock, or teacher mock. Never back-fill a prediction after seeing the outcome.

## Publication gate
- <30 linked outcomes or fewer than 10 pass / 10 fail: insufficient evidence.
- 30–99 balanced outcomes: provisional classification analysis only.
- 100+ outcomes: evidence-building; still requires external statistical review, holdout validation and subgroup fairness checks before publishing probabilities.

The API deliberately returns `probability_enabled: false` until a validated model is introduced.
