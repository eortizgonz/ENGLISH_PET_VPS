# PET Quest V46.24 — Error DNA™

## Purpose
Error DNA™ turns persisted errors and corrective evidence into an individual learner map. It is not a decorative heatmap: every coloured node is evidence-backed.

## Domains
- Grammar: Past simple, Present perfect, Prepositions, Articles.
- Listening: Times, Numbers, Opinions, Corrected information, Spelling.
- Reading: Inference, Detail, Text cohesion.
- Writing: Organisation, Content, Language.
- Speaking: Fluency, Pronunciation, Interaction.

## Evidence sources
`academic_error_events`, `academic_remediation_attempts`, B1-matrix `learning_events`, saved Writing rubric attempts, and persisted Speaking metrics.

## Colour contract
- ⚪ Insufficient: fewer than 3 observations. No diagnostic colour claim.
- 🔴 Critical: <60%.
- 🟠 In progress: 60–79.9%.
- 🟢 Mastered: >=80% with sufficient evidence.

For academic `error_code` patterns, recent remediation evidence is also honoured: three recent correct remediation attempts are required before the remediation path can contribute a mastery signal. Contradictory new practice evidence can keep the node below green; a historic correction does not permanently hide a current weakness.

## Actionability
Each node opens a detail view with score, evidence count, source and cause. Where Practice Bank metadata supports the pattern, Error DNA™ can create an immediate 10-item corrective set.

## Scientific honesty
Pronunciation/intelligibility remain automatic practice proxies and do not replace human examiner judgement. Error DNA™ is a formative learning diagnostic, not an official Cambridge assessment.
